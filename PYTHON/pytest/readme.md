pytest is used to test methods or functions if the expected answer is right or not

it uses "assert" keyword to check the given function works correct or not

<!-- Limitation -->
Pytest only collects tests that follow these rules:

  * File names start with test_ or end with _test.py (e.g. test_math.py)
  * Test functions start with test_ (e.g. def test_add():)
  * Test classes start with Test (and have no __init__)
